# Packaging

| File | Installed to |
|---|---|
| `penguinwave.service` | `/usr/lib/systemd/user/penguinwave.service` |

The unit is **not** enabled by `post_install`: user units are per-user and
packaging scripts run as root. The UI enables it on first launch, and
`penguinwave-cli` prints the enable command when it finds no daemon.

Shell completions are generated by the binary itself:

```sh
penguinwave-cli completions bash > /usr/share/bash-completion/completions/penguinwave-cli
penguinwave-cli completions zsh  > /usr/share/zsh/site-functions/_penguinwave-cli
penguinwave-cli completions fish > /usr/share/fish/vendor_completions.d/penguinwave-cli.fish
```
